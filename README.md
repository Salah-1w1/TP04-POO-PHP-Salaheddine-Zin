## Exécuter les scripts

Depuis la racine du projet, en ligne de commande :

    & "C:\xampp\php\php.exe" tp_poo\partie1.php

Ou avec le serveur interne :

    & "C:\xampp\php\php.exe" -S localhost:8000

puis ouvrir http://localhost:8000/tp_poo/partie1.php

PHP 8.1 ou plus est requis (`readonly`).
